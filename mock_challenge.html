⚡ Teacher Challenge: Point the spotlight

Surrounded by cargo crates, use your navigation tools to turn and face directly toward them one at a time.

🚧 Mission Specification

Challenge: Starting anywhere, surround the robot in the center of 3 blocks (Red, Green, and Yellow). Use gyro to turn directly at the blocks in any order.

🎯 Mission Parameters

  • Starting Position: Anywhere on the mat
  • Success Criteria: Point the robot at each of the 3 blocks while using the gyroscope to turn.

💡 Navigation Strategy

Measure the approximate degrees the robot would need to turn to face each block. Remember to reset the gyro yaw after each turn.

🤖 Programming Approach

🌊 Movement Sequence Planning

Step 1: Measure the degree the robot would need to turn to face the first block.
Step 2: Have the robot reset the yaw before performing any movement.
Step 3: Reset the yaw after the first turn and wait 1-2 seconds, before turning again to the second block.
Step 4: Repeat this for the 3 blocks.
Step 5: Tell the AI each step, including a request to reset the yaw, before sending the prompt.
Step 6: Trial and error to adjust the degrees needed for the turns.
Student's Example Command:

"At the start, reset my robot's gyroscope yaw. Repeat the following movement 3 times: my robot needs to turn 45 degrees to the right using the gyroscope. After turning, reset the yaw and wait 1 second."

🛡️ Safety Protocol

  • ⚠️ Remember to use gyro turns, not normal turns, for more precise movement.
  • 🔄 Multiple attempts encouraged
  • 📏 Measure or guestimate the degrees it would take for the robot to turn to the next block
  • 🤝 Team collaboration recommended

📦 Student Challenge: Colorful Crate Haul

Surrounded by crates, use your compass to turn, scan them to identify crate colors, and collect the one that matches your orders

🚧 Mission Specification

Challenge: Starting anywhere, surround the robot in the center of 6 blocks. Use gyro to turn and read blocks colors. When a designated color is found, have the robot grab it.

🎯 Mission Parameters

  • Starting Position: Anywhere on the mat
  • Success Criteria: Gyro turn towards the blocks and identify the designated color block with the color sensor before using the robot arm to grab it.

💡 Navigation Strategy

Raise the robot arm up before starting any movement so the color sensor can detect the block colors. Troubleshoot by having the robot print the color detected in the console.

🤖 Programming Approach

🌊 Movement Sequence Planning

Step 1: Measure the degree the robot would need to turn to face the first block.
Step 2: Have the robot reset the yaw before performing any movement. Raise the arm up to use the color sensor on the blocks.
Step 3: Reset the yaw after the first turn and read the color of the block before turning again to the second block.
Step 4: Repeat this until you find the designated block, then move forward to grab it with the robot arm.
Step 5: Tell the AI each step, including a request to reset the yaw, before sending the prompt.
Step 6: Trial and error to adjust the degrees needed for the turns.
Student's Example Command:

"At the start, reset my robot's gyroscope yaw and raise the arm by 45 degrees. Turn 45 degrees to the right and print the color detected with the color sensor in the console. Then reset the yaw. Repeat this until the designated color of RED is found."

🛡️ Safety Protocol

  • ⚠️ Remember to use gyro turns, not normal turns, for more precise movement.
  • 🔄 Multiple attempts encouraged
  • 📏 Measure or guestimate the degrees it would take for the robot to turn to the next block
  • 🤝 Team collaboration recommended
